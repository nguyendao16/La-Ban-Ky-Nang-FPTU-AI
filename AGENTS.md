## Agent skills

### Issue tracker

Issues and specs use local Markdown under `.scratch/<feature>/`. Before creating, reading, or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before assigning a triage status, read `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`. Before exploring domain concepts or proposing architectural changes, read `docs/agents/domain.md`.
