## **Job description**

As an AI Engineer Intern, you will contribute to the design, development, and deployment of AI-driven systems and backend services. You’ll collaborate closely with AI specialists, data engineers, and software developers to build intelligent applications and scalable APIs. This role offers hands-on experience with modern AI frameworks, backend technologies, and web integration.

## **Responsibilities:**

- Collaborate with cross-functional teams to design, develop, and deploy AI and backend solutions using Python and FastAPI.
- Support data preprocessing, analysis, and integration tasks for AI models.
- Implement, test, and optimize machine learning (ML) and large language model (LLM) applications.
- Work with databases - write queries, manage data, and integrate using SQL and MongoDB.
- Develop APIs and services that communicate through HTTP or WebSocket protocols.
- Collaborate on building AI-enabled web features; ReactJS knowledge is a plus.
- Document technical workflows, APIs, and development progress.
- Participate in testing and performance tuning to ensure reliability and scalability.

- Bachelor’s degree in Computer Science, Engineering, or related field.
- Solid understanding of AI concepts and machine learning fundamentals, with a good ML foundation.

- Basic experience with SQL and MongoDB for data management.
- Understanding of WebSocket or HTTP-based API communication.
